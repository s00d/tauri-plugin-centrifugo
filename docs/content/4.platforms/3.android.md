## TLS

The SDK's default TLS verifier on Android needs JNI and Gradle setup in the app. To make `wss://`
work with no setup, the plugin builds the client on Android with Mozilla's root certificates
([`webpki-roots`](https://crates.io/crates/webpki-roots)) instead.

The catch: certificates trusted only on the device (user-installed CAs, a corporate MITM proxy,
a self-signed dev certificate) are **not** trusted. Use a certificate from a public CA, or plain
`ws://` for local development.

CI builds the plugin for `aarch64-linux-android` and `x86_64-linux-android` to check this path.

## Reaching your dev server

- From the emulator, the host machine is `10.0.2.2`: `ws://10.0.2.2:8000/connection/websocket`.
- From a device on the same network, use the machine's LAN address, or
  `adb reverse tcp:8000 tcp:8000` and `ws://localhost:8000/...`.

The app needs the `INTERNET` permission, which the Tauri Android template already has.
