title: Overview
description: Where the plugin runs and what differs between platforms.
---

The client runs in Rust inside your app on every platform, so the JavaScript API, the events and
the behaviour are the same everywhere. What differs is TLS and how the device reaches your server.

| Platform | Status | TLS roots |
|----------|--------|-----------|
| Windows · macOS · Linux | ✅ tested in CI | OS trust store |
| Android | ✅ built in CI | Mozilla roots (`webpki-roots`) |
| iOS | ✅ | OS trust store |
