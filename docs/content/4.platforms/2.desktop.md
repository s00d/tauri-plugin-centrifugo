---
title: Desktop
description: Windows, macOS and Linux.
---

Nothing to set up. The SDK uses the OS trust store for `wss://` / `https://` (so corporate CAs
installed in the system work) and the OS proxy settings.

CI runs the unit tests and the end-to-end tests against a real Centrifugo v5.4.9 on Linux, macOS
and Windows.

On Linux, Tauri itself needs the WebKitGTK development packages to build (for example
`libwebkit2gtk-4.1-dev` on Debian/Ubuntu); the plugin adds nothing to that.
