## Versions

| Centrifugo | Status |
|------------|--------|
| v5.x | ✅ tested (CI runs v5.4.9, the oldest major the tests cover) |
| v6.x | ✅ same client protocol |
| v4.x | ✅ client protocol v2; no HTTP streaming |
| v3 and older | ❌ old client protocol |

The plugin speaks client protocol v2 (Centrifugo v4+). HTTP streaming (`httpStreamUrl`) needs
Centrifugo v5+ with `http_stream` enabled.

## Options the features rely on

Names are Centrifugo v5 options; v6 moved them into nested sections.

| Feature | Server option |
|---------|---------------|
| Anonymous connections (no token) | `allow_anonymous_connect_without_token` |
| Connection / subscription JWTs | `token_hmac_secret_key` (or RSA/ECDSA keys, JWKS) |
| Client publish | `allow_publish_for_client` / `allow_publish_for_subscriber`, or a publish proxy |
| Subscribe without a token | `allow_subscribe_for_client` (`…_for_anonymous` for anonymous) |
| History, recovery, `since`, positioning | `history_size` + `history_ttl` (+ `allow_history_for_client`) |
| Presence | `presence` (+ `allow_presence_for_client`) |
| Join / leave | `join_leave` |
| Delta compression | `allowed_delta_types: ["fossil"]` (v5.4+) |
| RPC / send | RPC proxy / send proxy |
| HTTP streaming | `http_stream: true` (v5+) |

## Test server

[`examples/server/centrifugo.json`](https://github.com/s00d/tauri-plugin-centrifugo/blob/main/examples/server/centrifugo.json)
is a v5 config for the example app (port 8001, anonymous access, history, presence,
join/leave, HTTP streaming). It is insecure on purpose; do not use it in production.

```bash
centrifugo --config examples/server/centrifugo.json
```
