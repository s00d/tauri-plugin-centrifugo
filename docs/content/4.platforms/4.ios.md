---
title: iOS
description: iOS devices and the simulator.
---

The plugin works on iOS like on desktop: the SDK uses the system trust store, so no setup is needed
for `wss://`.

- The simulator shares the Mac's network: `ws://localhost:8000/connection/websocket` reaches a
  server running on the Mac.
- A device needs the Mac's LAN address (or a public server).

iOS is not built in CI; report problems in the
[issue tracker](https://github.com/s00d/tauri-plugin-centrifugo/issues).
